# Anoy Nath — Portfolio

Personal portfolio and résumé site. A static site: `index.html` plus the files in `assets/`.

- `assets/Anoy-Nath-Resume.pdf` — résumé served by the Download PDF button
- `assets/brew-dashboard.webp`, `assets/brew-model.webp` — screenshots for the Brew & Co case study

No build step. Every push to `main` deploys to https://anoy-nath-portfolio.vercel.app.
